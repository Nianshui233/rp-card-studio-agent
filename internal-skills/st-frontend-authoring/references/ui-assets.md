# UI 字体与图标资产能力

这是一个可选的 UI 资产选择模块，不是所有项目的强制依赖。它帮助 Agent 选择中文字体、功能图标、内嵌 SVG、远程资源和回退方案，并把实际资产写入项目的 UI 需求账本与交付报告。

## 1. 两类资产的分工

### 字体

字体负责：

- 中文长文本的可读性；
- 时代、地域、职业和世界观气质；
- 标题、正文、数据标签的层级；
- 像素、档案、手写、古典、工业、终端等视觉签名。

字体不是装饰性最后润色。先确认正文可读性、字重、行高、窄屏换行和系统回退，再决定是否使用特殊展示字体。

### 图标

图标负责：

- 搜索、返回、关闭、展开、设置、刷新等通用动作；
- 人物、物品、任务、地图、事件、警告等信息识别；
- 触控按钮的快速识别。

功能图标和世界观美术要分开：图标库适合承载动作和通用语义，阵营徽章、仪式符号、特殊纹章和主题装饰应使用项目自己的 SVG/CSS/图形资产。

## 2. 可选资源来源

### ZeoSeven Fonts

适合中文字体检索、风格对比、字重选择和 Web 字体调用。Agent 可以根据 RP 主题先给出字体方向，再由用户选择或授权 AI 决定。具体字体的许可、语言覆盖、字重和嵌入方式以该字体页面为准，不把整个站点笼统标成一个许可证。

可选实现路线：

1. `design_reference`：只用于选型和风格说明，不进入运行时；
2. `remote_font`：通过远程 CSS/字体服务加载，必须登记远程依赖、版本/来源、系统字体回退和 `runtime` 证据；
3. `local_font`：下载需要的字重并放入项目维护源码；
4. `embedded_subset`：只嵌入项目实际需要的字形或局部字体，适合追求离线一致性的项目。

不要默认把完整 CJK 字体塞进角色卡。字体很大时，远程字体 + 可靠系统回退、局部子集或普通系统字体都可以是合理选择；由用户体验目标、网络环境和制品大小共同决定，不能用体积作为创作上限。

### Font Awesome Free

适合功能性图标和常见操作语义。默认优先提取实际使用的 SVG 并内嵌到最终 HTML；只有确实需要字体图标或完整图标运行时，才选择自托管 Web Font 或 SVG/JS 路线。

推荐顺序：

```text
项目专属 SVG/CSS 装饰
→ Font Awesome Free 的选定 SVG 功能图标
→ 字体图标（仅在有明确理由时）
→ 远程 CDN/Kit（仅在用户接受远程依赖时）
```

不要把完整 `all.css`、`all.js` 或整个图标字体库无差别装进角色卡。只保留使用到的图标、样式和必要代码，避免增加加载失败面与无意义体积。品牌图标另行记录，不把品牌标志当普通装饰。

## 3. 资产策略决策

资产选择必须同时记录：

```yaml
assets:
  font:
    strategy: system_stack | design_reference | remote_font | local_font | embedded_subset
    provider: ""
    family: ""
    weights: []
    language_support: []
    license: ""
    source_ref: ""
    fallback_stack: []
  icons:
    strategy: project_svg | font_awesome_svg | web_font | remote_library | css_only
    provider: ""
    selected: []
    license: ""
    source_ref: ""
    accessibility_labels: true
  remote_dependencies: []
```

`strategy` 是实现方向，不是用户必须理解的选项。用户只需表达“希望更像旧报纸”“按钮要清楚”“不要外链”“可以接受联网加载”等体验偏好；Agent 负责把它转换为技术路线。

## 4. 玩家端规则

- 正文默认优先可读性，特殊字体只用于标题、标签、徽章或主题区域；
- 中文字体必须检查长文本、标点、数字、英文、缺字和窄屏换行；
- 图标按钮必须有中文可见文字或可访问名称，不能只靠图形猜意思；
- 图标不能只用颜色表达状态；危险、选中、禁用和成功状态要有文字、形状或辅助说明；
- 触控目标和间距按照实际移动端体验检查；
- 明暗主题若启用，字体、图标、边框和状态对比度必须分别检查；
- 远程资源失败时必须保留可读文字、系统字体、内联 SVG 或 CSS 回退；
- 不能把“使用了字体/图标库”误当成 UI 完成，信息架构、交互和真实数据链仍需独立完成。

## 5. 与 SillyTavern 交付的关系

字体和图标可以出现在：

- 开场介绍/创角 HTML；
- 持续消息状态 HTML；
- 超重型/0 层消息应用；
- 用户明确要求的其他卡内 HTML 表面。

它们不能默认要求修改 SillyTavern 本体或全局安装插件。远程字体或图标库属于项目运行依赖；最终报告必须说明：

- 是否需要联网；
- 失败时显示什么；
- 是否有系统字体或内联 SVG 回退；
- 是否在真实 SillyTavern 中验证过；
- 使用的具体资源、版本/来源和许可记录。

## 6. 不增加创作上限

资产策略只负责可运行性、可读性、可回退性和来源记录，不限制：

- 字体数量；
- 图标数量；
- SVG 行数；
- UI 页面数量；
- 远程资源数量；
- 最终 HTML 或角色卡大小。

性能和加载成本只作为报告与优化建议。只有资源断链、无法读取、导致页面空白或让核心操作失效时，才进入整合阻断。
