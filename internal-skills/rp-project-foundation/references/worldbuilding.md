# 世界观创作

世界必须在 `<user>` 不介入时也能运转。优先建立真正影响 RP 的因果结构：

- 核心规律与不能被随意破坏的边界；
- 地区、制度、组织、阶层和资源流动；
- 历史造成的当前压力，而非无用途年表；
- 不同群体的目标、冲突、妥协和日常；
- 当前正在发生、会自行推进的事件；
- 普通人的生活方式、信息来源和现实限制；
- 对场景、角色和玩法产生实际后果的规则。

使用可读中文 YAML 或自然文本。世界书切片按稳定主题和调用需要决定：少量常驻骨架，其余按关键词、位置、深度或 EJS 调用。不要为了模板完整堆无用设定，也不要把世界写成计算机配置。

围绕当前世界观缺口进行多轮、多问题访谈，每次回答后立即补写或修改实际世界内容。用户放权后直接补全。阶段结束时由主 Agent 在对话中给出总结报告，不生成总结文件。
