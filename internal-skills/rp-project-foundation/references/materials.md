# 材料与旧卡盘点

读取用户明确提供的材料，只处理当前项目需要的内容。用户授权的仓库、文档和示例可以参考，但最终交付不依赖参考路径。

旧卡修改、审查或转换开始前：

1. 在工作目录保留原始输入副本；
2. 盘点卡面字段、CharacterBook、独立世界书、正则、Tavern Helper、MVU/EJS、HTML、用户条目、未知扩展和媒体；
3. 对每项给出保留、迁移、重写、清理或待确认结论；
4. 识别真实人物、世界、系统和运行组件，不因 `data.name` 自动假定原卡是单人物卡；
5. 清理旧用户资料后提供独立、中文、默认禁用的 `<user>` 空白模板；
6. 原始副本只用于追溯，不进入运行导入清单。

不需要建立 `project.yaml`、状态镜像、迁移数据库或装配清单。一份简短盘点 Markdown 或直接在对话中报告即可。
