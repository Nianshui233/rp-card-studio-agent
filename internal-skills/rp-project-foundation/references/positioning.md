# 项目定位

定位只需要确定会实际影响创作的事实：

- 项目是单人物、群像、大世界、玩法型还是混合型；
- 玩家反复获得的核心体验与主要循环；
- 整体气质、内容密度和节奏；
- 适合作为 `data.name` 的标题；
- `data.description` 应传达的项目入口与核心合同；
- 本次确实需要的世界、角色、系统、场景、运行时和 UI 范围。

每轮最多询问 3–5 个问题，并给出一个结合用户材料的推荐。用户完全放权时直接锁定方向并开始写内容，不生成定位账本或阶段总结。

判断单人物卡时看项目是否只有一个预先创作的卡内核心角色，不把 `<user>` 当成待创作的配对主角。群像、世界和玩法项目使用整体标题，不用某个 NPC 的姓名冒充项目名。
