# 灵感脑暴与创作母纲

## 目标

把用户无需预先整理的零星灵感转成一份后续阶段能够直接继承的“可游玩创作母纲”。脑暴负责发散后的整合与收束，不负责替用户制造问卷，也不把开放 RP 写成必须依次发生的固定剧情。

## 启用判断

预检根据当前输入先给建议，再由用户确认：

- 只有一句题材、几个画面、人物感觉或相互矛盾的碎片时，建议启用；
- 用户希望重构旧卡的整体方向时，建议启用；
- 已有清晰企划、只做定向修改、纯审查、纯前端或纯运行时任务时，建议跳过；
- 用户明确要求启用或跳过时直接服从，不额外设置门槛。

启用问题本身可以作为功能开关直接询问，但应同时说明当前推荐、理由和影响。例如：

```text
问题：是否先启用脑暴，把这些零散灵感整理成可继续制作的创作母纲？
建议：我建议启用；你不需要先分类，可以继续直接丢画面、关系、对白和“不想要什么”。
为什么：目前最有价值的是先找到这些碎片共同承载的体验，避免世界、角色和开场分别写得不错却不像同一个作品。
影响：启用后先完成整体整合和场景压力检验；定位阶段会直接继承结果，不重复从零询问。
```

## 输入吸收

允许用户以任意顺序提供：

- 一句话题材或类型组合；
- 画面、对白、梦境、事件或开场片段；
- 人物气质、关系拉扯、性格反差或成人内容方向；
- 想要的玩法、节奏、情绪和审美；
- 喜欢的参考特征；
- “不想做成什么”或不接受的套路；
- 彼此矛盾、无法确定取舍的多个方向。

不要要求用户先填写世界、角色、系统、场景和开场栏目。Agent 在当前回复中自行区分：必须保留的硬锚、反复出现的情绪、关系张力、世界动力、场景种子、可替换装饰和反向边界；这种分析只用于形成创作内容，不写成盘点或决定文件。

## 第一轮合同

面对基础想法时，第一轮必须按以下顺序：

1. 解释这句话已经包含的体验承诺和天然矛盾；
2. 写出一个暂定的一句话整合方向；
3. 只选择 2–4 个会改变整个项目的承重问题；
4. 每个问题给出明确建议、理由和影响；
5. 告知用户可以接受建议、修改局部或授权 Agent 继续决定。

不要以名称、年龄、地点数量、势力数量、设定字段或技术选型开场。用户没有提供人物和剧情时，Agent 应先承担第一版整体构思。

例如用户只说“我想做一个民国志怪的开放大世界”，应先识别：

- 民国带来的新旧制度、交通、信息与地方秩序冲突；
- 志怪需要地方规则、禁忌、契约和不可简单善恶化的异类；
- 开放大世界需要自由路线、区域联动和无人介入时仍会推进的事件，而不是只增加地点数量。

首选整合可以是“现代交通和新式制度正在破坏各地沿用已久的人异旧约，玩家沿交通网络介入彼此关联的地方异闻”。随后只询问历史真实度、玩家反复做什么、怪异规则统一到何种程度等承重选择；用户接受建议后立即写出世界动力、典型循环、代表地区或场景证明，不继续索取空白设定。

## 整合动作

按真实缺口选择动作，不机械跑固定题数。

### 1. 提取共同核心

说明多个碎片共同指向的体验或冲突，并区分核心与表现形式。例如“雨夜、废弃空间站、冷淡医生、循环、回不了家”可能共同指向无法完整挽回的封闭关系，而不只是科幻解谜。

### 2. 提出首选脊柱

给出一个能够连接题材、人物、世界和玩法的首选方向。必要时提供少量备选，但说明各自会把作品带向怎样不同的体验，不让用户面对无解释菜单。

### 3. 建立可游玩动力

把抽象主题转成：谁想要什么、谁会阻止、什么会自行变化、玩家为什么能够介入、典型一轮怎样发生、结果怎样留下后果。

### 4. 保留开放空间

母纲固定承重因果，不替玩家预设唯一身份，不规定唯一正确路线，不把所有谜底、关系结局和地区结果提前锁死。开放不是内容空白，而是多个有后果的可行方向。

### 5. 场景与压力证明

至少选择一个高风险点写成具体片段，优先检查：

- 初次进入时是否马上表现核心体验；
- 一次普通循环是否足以持续游玩；
- 拒绝、失败或信息不足后是否仍能继续；
- 玩家不介入时人物、势力和地区是否会行动；
- 一处选择是否会对关系、资源、路线或其他地区产生连锁影响。

## 每轮输出形态

用户回答后，回复优先包含：

```text
我据此把当前方向改成了什么
→ 已经写出的母纲片段或场景证明
→ 现在剩下的一个最有价值缺口
→ 问题＋建议＋为什么＋影响
```

可以一轮处理多个紧密相关问题，但不能连续多轮只收集信息。用户只回答一部分时，先用已确认内容推进母纲，再处理剩余缺口。

## 母纲语义覆盖

最终母纲不要求机械标题和固定篇幅，但应按项目需要覆盖：

1. 暂定标题或识别名与一句话核心；
2. 核心玩家体验、气质和明确不做成什么；
3. 玩家进入条件、行动空间和可选身份范围，不固化最终 `<user>`；
4. 世界当前局势、利益分配与无人介入时的变化；
5. 核心人物类型、关系张力或势力立场；
6. 可反复发生的典型 RP 循环；
7. 开局切入、压力升级、分支和长期后果；
8. 至少一个代表性场景；
9. 哪些变化必须被记住、玩家需要看到什么反馈，只描述体验需求；
10. 防止后续世界、角色、系统和开场偏离的承重约束。

轻型项目可以合并内容；群像、长期玩法和开放世界应增加多情境、无人介入与连锁后果证明，而不是扩大百科规模。

## 特殊风险

### 开放世界

地点多不等于开放。必须至少有自由路线、地区差异、独立行动者、无人介入演变和跨地区后果。不要默认存在唯一救世主线。

### 参考作品

提炼用户喜欢的结构、气质和体验，不把参考作品的专名、剧情和独特表达直接换皮复制进母纲。

### 成人内容

沿用预检已经确认的 NSFW 开关。启用时可以把成人关系与题材纳入真实创作方向；不重新进行边界问卷，不创造运行时年龄门禁，也不创作或迁移涉及未成年人的成人性内容。

### 旧卡重构

脑暴只决定新整体方向，不在这里执行旧卡组件盘点和迁移。后续材料阶段仍需保留原始输入并处理实际文件。

## 向定位阶段交接

完成后由主 Agent 在当前对话给出一份统一母纲。定位阶段必须：

- 直接从母纲提取核心体验、典型循环、项目形态、标题方向、`data.description` 入口和制作范围；
- 只询问母纲中仍然存在且会改变制作合同的缺口；
- 不重新询问“你想做什么”“想要什么感觉”或已经完成的同义问题；
- 将脑暴中的开放可能性收束为可执行定位，但不得把开放分支误写成固定剧情。

若用户明确要求保存 `创作总纲.md`，它属于真实创作参考；只保留当前作品内容，不保存过程状态。阶段状态、问题答案、选择理由和完成进度仍然只存在于当前对话。
