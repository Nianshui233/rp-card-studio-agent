# SillyTavern 制卡工坊

**从一个想法、一张旧卡或一堆零散材料开始，逐步创作 SillyTavern RP 角色卡。**

你可以用它梳理世界与人物、设计玩法与开场，按需要加入世界书、变量或卡内界面；也可以让它检查现有内容之间是否一致，并整理需要导入的文件。

它面向角色卡作者和 RP 创作者。你不必先准备完整设定，也不需要先学会变量、正则或脚本；告诉它想做什么、已有材料是什么，再一起确定重要选择即可。

## 使用方式

将本仓库作为 Codex Skill 安装后，在对话中显式调用：

```text
$rp-card-studio
```

然后描述你的想法或要处理的角色卡。本 Skill 使用显式调用，不会自动接管普通对话。

## 可以从这里开始

### 从一个想法开始

```text
$rp-card-studio
我想做一张关于【题材、角色或玩法】的 SillyTavern 角色卡。
先帮我整理出一个有趣、能继续发展的方向，再一步步做。
```

### 继续制作旧卡

```text
$rp-card-studio
我有一张旧卡和一些配套文件。请先帮我看懂现有内容、指出需要保留的部分，再一起决定怎么改。
```

### 只处理一个部分

```text
$rp-card-studio
我只想改这张卡的开场页（或状态栏/世界书/角色设定），请沿用其他已经确定的内容。
```

## 创作过程

- **从你的材料出发。**零散构想可以先整理成可玩的方向；已有明确计划时，可以直接进入指定部分。
- **重要选择会先和你确认。**访谈会拆开真正不同的选择，说明推荐理由和影响；不会用一个笼统问题替你定下一串关键设定。
- **你可以决定页面的样子。**制作开场页或状态栏时，可以提出喜欢的氛围、参考作品、希望展示的信息、排版偏好和操作方式。实现细节由工具处理，不要求你回答 CSS、API 或脚本问题。
- **后续想法可以带动前面调整。**如果制作界面时发现需要新的角色属性或游戏规则，会先确认它只是展示现有信息，还是会影响后续玩法；需要新增长期状态时，再补齐其含义和规则，然后接回界面制作。
- **只按需要加入技术组件。**轻量角色卡不必自动加入变量、脚本或复杂界面；复杂功能会说明依赖和用途。

## 可以创作和检查的内容

- 世界、角色、NPC、关系、场景、事件和玩法；
- 开场、备用开场、玩家创角和开局路线；
- 世界书，以及需要长期记住的角色卡状态；
- 游玩中的状态栏、任务、地图、物品和行动界面；
- SillyTavern Regex、MVU/EJS 与 Tavern Helper 脚本（仅在项目确实需要时）。

开场/创角页面和游玩中的状态栏用途不同，可以只做其中一个，也可以分别定制。

## 文件与验证

项目完成后，可按实际需要整理角色卡、世界书、脚本、Regex、HTML 和简短导入说明。使用的技术组件不同，所需扩展和导入步骤也可能不同。

文件格式、组件配对和部分规则可以先做静态检查；但**静态检查通过不等于已在 SillyTavern 实际导入和运行**。如果没有在目标 SillyTavern 环境中实测，结果会明确标注“尚未实机验证”，不会把模拟测试说成运行通过。

本工具不会默认修改 SillyTavern 本体或你的用户数据。真实导入、生成、Swipe、保存和重载测试需要可用的目标环境，并可能改变聊天或角色数据；是否执行会先明确范围。
