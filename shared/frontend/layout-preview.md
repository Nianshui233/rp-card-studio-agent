# 制作者的前端简易预览

这是制作时给用户看的结构草图与渲染预览，不是 RP 页面里的主控资料预览，也不是新的创作阶段或确认账本。不能等用户自己画示意才讨论布局，不能只列功能名称或问“A/B/C”。

## 默认怎么展示

1. 前端访谈开始，有第一批用途/材料后，就由 Agent 在对话中画出推荐结构：常驻信息、分区、当前页、字段层级、控件与操作结果。未知内容标待定，不为画满草图新增世界事实或变量。
2. 用户纠正后，在同轮同步当前页面记录，再展示修改后的草图；标签切换、折叠展开、详情弹窗、创角下一步等会明显改变内容的状态至少展示一项。多页面先给总体导航，再逐页展示当前讨论页，不堆出整套长图让用户找差异。
3. 开始完整实现前，展示当前选定结构和关键交互状态。已有明确决定或自由设计授权时直接按范围实现，不增加“必须批准预览”的重复门；需要用户决定的事项仍走现有访谈规则。看到草图、图片或回复“继续”不等于接受整个阶段。
4. 有当前真实 HTML/导入内容时，工具可用就生成并在对话显示实际渲染图，或打开宿主提供的可访问预览。不能只报一个保存位置、贴代码或要求用户导入酒馆后才能第一次看到界面。已有成品的定向修改可先展示现状，再展示变化，不强迫重做整轮访谈。

结构草图只说明排列和交互，不承诺配色、字体、动画、图形和最终尺寸；必须明确它不是成品截图。真正的视觉选择按原有前端设计合同落实，不得把“草图已经看过”当成只写简陋文字 body 的理由。没有图片/浏览器工具时仍在对话画草图，并说明实际视觉尚未预览；不能假称已截图或把缺截图能力变成全部创作阻断。

界面内容依当前项目决定。顶部总览、标签页、衣着细分、物品折叠、人物详情等只是可能的结构，不是所有卡的必选项，不从样品矩阵复制字段或流程。

## 使用现有页面记录

继续使用 production.interviews.<stage>.surfaces；草图不另建访谈文件、授权记录或第二份状态树。页面/字段/操作可加用户可读 label。字段可有 example，但只用于带“示例”标识的制作预览；不能写进世界书、初值、主控资料或作为真实数据缺失时的运行兜底。

layout.value 仍是布局说明与当前决定引用；同一个 layout 下的 blocks 描述实际排列。结构或字段更正时同步 blocks、fields、actions 与决定投影，不仅改摘要/哈希。节点只引用当前字段/操作 id，不复制一份字段名称、数据或操作规则：

- section：label、blocks，表示常驻区或普通分区。
- tabs：id、label、items[{id,label,blocks}]，可有 selected。
- fold：id、label、blocks，可有 open，表示展开/收起。
- dialog：id、label、action、blocks，表示某个已声明操作打开的详情窗口。
- field：field，引用 fields 的 id，名称、呈现方式与例值实时派生。
- action：action，引用 actions 的 id，按钮名与结果实时派生。
- note：text，仅用于标明布局上尚待决定的部分，不冒充已实现字段。

已声明字段/操作须在某个实际页、折叠或详情状态中出现，不能漏掉“收起里面的内容”；允许在简介与详情等不同位置复用同一字段。每个交互容器 id 唯一。旧项目没有 blocks 时可以暂时生成明确标“位置未展开”的清单，但不能当作完整布局已展示；新增/重做布局按当前项目补充结构。

默认生成草图的工具：

```text
node scripts/frontend/preview-layout.mjs --root <项目> --stage message_frontend --surface <页面id>
node scripts/frontend/preview-layout.mjs --root <项目> --stage message_frontend --surface <页面id> --tab <标签区id>=<标签页id> --expand <折叠id> --dialog <详情id>
```

开场/创角用 opening_frontend。可重复 --expand/--dialog；程序只读取当前记录、不执行按钮、不修改用户决定或写入变量。--json 输出机器记录，默认输出可以直接展示的 text 围栏。没有 Node/依赖时由 Agent 按相同结构手工画草图，标明工具未运行；不要求用户填写 JSON 或懂技术 id。

## 真正 HTML 的渲染图

复用 scripts/frontend/run-browser-fixtures.mjs 的当前精确导入内容、真实正则替换、主路/兜底和受控输入，不另造展示用假 HTML：

```text
node scripts/frontend/run-browser-fixtures.mjs --root <项目> --fixtures 制作文件/检查/<当前用例>.json --preview <用例id> --preview <另一个状态用例id>
```

选择首屏及实际标签/弹窗/展开操作后的正向用例；桌面和窄屏按实际 viewport 分别展示。截图使用受控消息容器，明确是 browser-fixture、runtime:not_run，外联资源禁用；不冒充真实酒馆账户、扩展、生成或持久化已经成功。外联图片/字体或宿主依赖导致预览受限时说明限制，不能拿空态冒充完整视觉。Agent 必须实际查看图片后再展示，检查内容、文字、遮挡和空白；有宿主实机截图时按其真实证据另报。

图片仅保存在制作文件/项目记录/检查结果/前端预览，命名和当前索引绑定用例、viewport 与精确目标内容；每次截图只保留本轮指定的工具预览集合，不存旧版本/备用界面，也不修改源码或导入包。只清理索引中且字节未被改动的本工具图片，用户另放/修改的图片不得删除或覆盖。HTTP、WebSocket 和 Service Worker 外联均阻断；截图失败不能借用上轮图片。超长页面截图若截断必须明示，不能当作全部内容已展示。

草图和图片的解释只在对话/制作记录中；不进入实际 RP 正文、世界书、Greeting 或正常运行界面。预览不是用户接受，也不是静态/浏览器/真实宿主验收的替代。
