# 当前对话进度画板

每次完成真实内容、修改、决定、测试或阻断变化后，在当前对话刷新一次。必须放在 Markdown fenced code block 中：

```text
【RP 项目进度画板】
项目：<标题>
阶段：<阶段>（制作进度）
用户审阅：<状态>
后续推进：<待交接时等待用户>
校验边界：用户来源真实性未核验；不是宿主硬锁

阶段账本
- <全部阶段的进度、代定授权、用户审阅分别显示>

当前授权
- <AUTH ID、范围、排除项、真实用户原话定位、交接到期>
范围：<本轮确认范围>

已完成（制作事项，不代表用户接受）
- ✓ <事项>（文件/证据）

进行中
- → <事项>

待决定
- ? <事项>（影响）

暂缓
- · <事项>（暂不计入本轮）

阻断/待实测
- ! <事项>（解除条件）

下一道门
- ⇒ <下一步>
```

画板状态来源于 `制作文件/项目记录/authority.md`、`制作文件/项目记录/NEXT.md`、`制作文件/项目记录/acceptance.json` 和当前对话刚完成的动作。它是对话中的实时投影，不是新的项目正典。
