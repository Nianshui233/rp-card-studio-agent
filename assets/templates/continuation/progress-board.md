# 当前对话进度画板

每次完成真实内容、修改、决定、测试或阻断变化后，在当前对话刷新一次：

```text
┌─ RP 项目进度画板 ─────────────────────┐
│ 项目：<标题>       阶段：<阶段>        │
│ 范围：<本轮确认范围>                  │
├─ 已完成 ──────────────────────────────┤
│ ✓ <事项>（文件/证据）                 │
├─ 进行中 ──────────────────────────────┤
│ → <事项>                              │
├─ 待决定 ──────────────────────────────┤
│ ? <事项>（影响）                       │
├─ 暂缓 ────────────────────────────────┤
│ · <事项>（暂不计入本轮）               │
├─ 阻断/待实测 ─────────────────────────┤
│ ! <事项>（解除条件）                   │
├─ 下一道门 ────────────────────────────┤
│ ⇒ <下一步>                             │
└───────────────────────────────────────┘
```

画板状态来源于 `.rp-card/authority.md`、`.rp-card/NEXT.md`、`.rp-card/acceptance.json` 和当前对话刚完成的动作。它是对话中的实时投影，不是新的项目正典。
