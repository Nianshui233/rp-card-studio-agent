# 旧档案改造：回声车站

这是一个专门用于 `edit`/`audit` 回归的原创样本。它不把旧卡直接当成新需求，而是先保留原始输入，再逐项决定保留、迁移、清理或待确认。

## 它验证什么

- `src/original/original.json` 是不可改写的原始输入副本。
- `src/original/preserved.json` 记录未知扩展和旧字段的保真结果。
- `src/user-character.yaml` 与世界书中的 `<user>` 条目都是独立、中文、默认禁用的空白模板。
- 旧状态标记、隐藏正则和脚本都有迁移结论；没有脚本就不能声称 MVU/变量链已经存在。
- 改造后的 HTML 是完整 `body + CSS + JS`，正则配置与 HTML 分开交付。
- 对涉及未成年人的成人性旧内容只执行 `clean_and_omit`：保真副本可以留存输入，但维护源和交付包不包含它，也不加入任何运行时年龄门禁。

## 它不保证什么

这个样本不规定所有旧卡都要保留旧 UI，也不规定所有变量都必须迁移到 MVU。它只演示“先审查、再决定、再重做”的证据链。
