# 星港观测台：稀疏数据重型 UI

这是一个专门验证“体验等级与变量数量分离”的原创样本。它只有少量权威动态字段，但仍然提供完整的重型消息内应用：导航、筛选、详情、时间线、派生读数、宿主行动和失败回退。

## 关键原则

- `experience_level: heavy` 不会因为 `data_density: sparse` 自动降级。
- 权威变量只负责真实事实；静态模块负责世界资料；派生视图只从真实输入计算；搜索、筛选、页签和弹窗属于本地 UI 状态。
- 缺失数据使用“尚未建立 / 暂无记录 / 宿主不可用”，禁止用假数字填满页面。
- 正则只负责捕获 `<星港观测台/>`，完整 HTML 另行交付。
