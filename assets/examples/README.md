# 运行技术示例

这里只保留三条可核对的最小路线，不是强制模板：

- `core-static-rp`：纯 SillyTavern 静态正则显示，无消息 JavaScript；
- `tavern-helper-iframe-rp`：Tavern Helper fenced HTML 消息 iframe；
- `mvu-ejs-bridge-rp`：MVU 原生 Schema + Tavern Helper ScriptFolder + ST-Prompt-Template 明确只读桥。

所有示例已按当前源码合同做静态核对；真实导入、网络和浏览器生命周期仍标记 `runtime: not_run`，不能冒充实机通过。
