# 自包含原创样本矩阵

这些样本全部由 `rp-card-studio` 独立创作，不引用外部卡片、仓库、网页、源码、设定或素材。

它们不是用户项目，也不是最终交付物；用途是让技能在没有外部资料的情况下，仍能看到不同 SillyTavern RP 包路线的完整结构。

| 样本 | 覆盖重点 |
|---|---|
| `self-contained-rp` | 非 MVU XML 状态契约、完整状态 HTML、完整/流式变量隐藏、宿主动作回退 |
| `mvu-native-rp` | 原生 MVU、`[initvar]`、更新规则、变量显示清理 |
| `mvu-zod-rp` | MVU_ZOD、宿主预装、Schema/default 初始化、EJS 上下文 |
| `opening-ui-rp` | 开场介绍/创角前端与持续状态栏分离 |
| `multi-surface-rp` | 多个功能页面、多个标记、选择/通知/状态三类正则消费者 |
| `zero-layer-rp` | 超重型/独立前端，消息 HTML 作为主要游玩表面 |

每个样本都额外包含 `src/runtime/opening/创角变量桥.yaml`。它们分别演示：非 MVU 通过 `<user>`/XML 主控设定块交接、原生 MVU 通过更新管线提交、MVU_ZOD 覆盖默认值、开场页表单生成主控块、多页面共享同一份设定，以及 0 层前端由宿主脚本完成写入与回读。样本不会把聊天楼 `data` 附件冒充成运行时变量更新。

样本只提供抽象技术路线和原创内容。技能不要求用户阅读外部教程，也不会把这些样本之外的路径自动当作材料。
