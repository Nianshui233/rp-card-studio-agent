# 《我，非我》重构版 · 导入说明

> 这份说明是给人看的文档，**不是**要导入酒馆的组件。真正需要导入的是下面第 2 节列出的 5 个文件。

## 1. 这是什么

原卡《我，非我》的规范化重构版：**一张角色卡 ＋ 一份独立世界书 ＋ 一份独立的酒馆助手脚本文件夹 ＋ 一份独立正则文件 ＋ 两个自包含页面（入口页、消息状态栏）**。

角色卡本身**不内嵌**世界书、正则或脚本（避免同一份内容存在两份）；世界书、正则、脚本都作为独立文件导入，由你自己选择绑定。

## 2. 文件清单与导入顺序

按顺序做，前 3 步是一次性的环境准备：

| # | 做什么 | 文件 |
|---|---|---|
| 1 | 在酒馆里安装并启用 **酒馆助手（Tavern Helper）** 与 **MagVarUpdate** | — |
| 2 | 用酒馆助手的「脚本管理」导入脚本文件夹，并启用其中两个脚本 | `酒馆助手脚本/我，非我.MVU运行脚本.folder.json` |
| 3 | 导入世界书 | `世界书/我，非我.世界书.json` |
| 4 | 导入角色卡，并在卡片的「世界书」里绑定上面那份世界书（名称应为 **我，非我**） | `角色卡/我，非我.重构版.json` |
| 5 | 导入正则文件，作用域选**角色卡**（绑定到这张卡），并保持 5 条规则**一起导入** | `regex.json` |
| 6 | 新建聊天，从第 0 楼开始 | — |

两个 HTML 页面**不需要手动导入**：它们已经按「标记 → 正则替换成 fenced html → 酒馆助手渲染」的方式接线，正则文件里已经包含页面全文，改页面就等于改正则，两边必须一致，所以不要单独改其中一个。

- `原始HTML/我，非我.开场入口页.html`：进入作品前的一次性登记页（第 0 楼渲染）
- `原始HTML/我，非我.消息状态栏.html`：正式游玩中每楼显示的状态面板

> 直接打开这两个 `.html` 只能看到页面骨架（它们要在酒馆的消息里才有数据），所以请把它们当作「可读源文件」，不要双击当网页用。

## 3. 为什么第 0 楼只有一行标记

第 0 楼的正文是一行 `<我非我开场/>`。这是**故意**的：

- 正则把它替换成完整的登记页，由酒馆助手渲染成消息里的页面；
- 页面负责介绍世界、选路线、分步填写主控资料、生成**可复制的资料块**；
- 真正开始剧情的四条开场白是**四条真实开场**（公路、商业区、医疗设施、郊野），在开场页看完介绍后由你自己手动切换选择。

如果你**没有**安装酒馆助手，第 0 楼就只会显示这一行标记。这时候两个办法：直接切到四条开场之一开始玩（玩法完全正常），或者先装上酒馆助手再回来。

## 4. 主控资料怎么生效（重要）

开场页只负责**生成一段文字**，它不会替你写任何东西。真正的流程是：

1. 在开场页填写资料 → 点复制，得到一段 `【我，非我·主控资料】…` 文本；
2. **你自己**把它存到世界书里那条**空白主控资料**（默认禁用，需要你手动启用并粘贴），或者直接写在聊天消息里；
3. 开局后模型读到这份资料，把内容登记进这一楼的状态；
4. 状态栏的「我」分区这时才会显示你的资料。

注意区分世界书里两条容易混淆的条目：

- **空白主控资料**：给你粘贴主控资料用的，需要你自己启用；
- **[initvar] 初始化基线**：状态初值，**必须保持禁用**，启用它会让一整份状态文本当成普通设定塞进 Prompt。

如果开场跑完了但状态栏还写着「未登记／未选择」，说明登记没生效：**保留你的原话，重新生成一次 AI 回复**即可，不要去世界书里手工补写运行状态。

页面不做的事（刻意的）：不创建/修改/删除/启用世界书条目、不发送消息、不自动切开场、不改状态、不覆盖输入框。剪贴板被浏览器拒绝时，页面会给出可选中全文和手动复制提示。

## 5. 日常游玩要注意的几点

- **状态栏每轮自动出现**靠模型每轮在回复最后输出一行 `<StatusPlaceHolderImpl/>`。模型偶尔漏掉时，这一楼就没有状态栏——不影响游玩，下一轮会自动恢复。
- 状态栏是**只读**的：它只读这一楼（以及当前 Swipe）的状态快照，不会替你改任何数值，也不会代替你发言。
- 状态栏里的数字是**给你看的**，不代表角色自己知道这些数值（比如「觉醒代价 62」不会让角色突然说出这个数字）。
- 五条正则要一起导入，不要把其中某条单独拆出来用，也不要在酒馆里手工改写正则内容。
- 世界书里带关键词的条目按关键词触发；常驻条目是世界观、生存规则、系统规则这类每轮都要在场的内容。
- 世界是开放的：你不填主控也能玩，世界、NPC、势力会按自己的逻辑运行。

## 7. 尚未验证的部分（请据此预期）

以下是**静态检查通过、但还没有在真实酒馆里跑过**的环节，第一次使用时请按这个顺序体验并留意：

1. 入口页在消息里是否正常渲染、窄屏与键盘操作是否顺手；
2. 复制按钮在你的浏览器里是否成功（失败时会走手动复制提示）；
3. 资料块存进世界书后，开局那一轮是否被登记进状态栏；
4. 第 0 楼标记是否被替换成页面、四条开场是否都能手动选择；
5. 状态栏是否每轮出现、数值是否与你看到的剧情一致、编辑消息或切换 Swipe 后是否重新读取、重载与切换聊天后是否仍正确。

以上任何一项不符合预期时，先记录「你在哪一步、看到什么」，再决定是改页面、改正则还是改世界书条目——**不要边玩边手工改正则或世界书条目**，那会让文件与源不一致。
