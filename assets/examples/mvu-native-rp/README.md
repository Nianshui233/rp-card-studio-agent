# 纸鸢台：原生 MVU 样本

覆盖一条带显式 `[initvar]` 的原生 MVU 链：

```text
真实初始值 → [initvar] 世界书条目 → MVU 更新规则 → 完整/流式变量清理 → 状态读取
```

所有内容均为原创本地夹具，不包含远程加载器。真实项目如果选择卡内 Loader，应把经过验证的 Loader 作为 Tavern Helper 源装入；这里用本地占位脚本只演示装配关系。

`src/runtime/opening/创角变量桥.yaml` 额外演示开场表单如何把名称、区域和情绪映射到 `stat_data`，再通过真实更新块提交并读回；只把字段放入聊天楼 `data` 不算初始化成功。
