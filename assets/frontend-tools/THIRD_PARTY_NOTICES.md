# 图标与实现依赖

工具界面的图标来自 lucide（ISC），通过项目锁定版本打包；生成的页面保留其代码许可注释。图标不构成 RP 作品事实或默认视觉风格。

HTML 与 CSS 源码回写使用 parse5（MIT）和 PostCSS（MIT）；构建使用项目已有 esbuild（MIT）。各依赖的许可原文随其 npm 包提供。设计资料、阶段用法和合成演示为本项目独立编写，未复制 TavernWeave 的指南、目录、代码或历史记录。

外部参考只保存定位入口与独立编写的采用建议，不随包分发源站的页面、字体、图像、模板或商业素材。实际采用资源须核对对应来源与许可。
